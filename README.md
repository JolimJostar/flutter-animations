# Flutter Animation Showcase

A small Flutter app that demonstrates common animation patterns: implicit animations, `AnimatedContainer`, staggered list entrances, Hero transitions, and physics-based motion.

## Getting started

```bash
flutter pub get
flutter run
```

Works on iOS, Android, macOS, web, Windows, and Linux.

## Demos

| Demo | Concepts |
|------|----------|
| Implicit animations | `AnimatedAlign`, `TweenAnimationBuilder`, `AnimatedContainer` |
| Animated container | Duration, curves, layout morphing |
| Staggered list | `AnimationController`, `Interval`, `CurvedAnimation` |
| Hero transition | Shared element transitions between routes |
| Spring physics | `FrictionSimulation`, `animateWith` |
